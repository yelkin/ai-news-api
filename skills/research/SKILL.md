# Research

Before implementing a code change involving PostgreSQL vector queries or AI API calls:

1. Write a concise ADR in `adrs/` stating the problem, decision, alternatives, and tradeoffs.
2. Support material technical claims with links to credible, existing research articles. Check that each article exists and supports the cited claim; do not invent citations.
3. Open the ADR for developer review with Plannotator, wait for feedback, and address it before changing code.

Follow the `plannotator` skill for the review command and feedback workflow.

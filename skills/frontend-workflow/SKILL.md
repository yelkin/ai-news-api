# Frontend workflow

This is a minimalistic no-build-required frontend for this app. Use minimal code, simplistic design
with the main goal of keeping it minimal, simple to read, good to be used as a tutorial.

## Wireframes

1. Modify or create an appropriate wireframe in `wireframes/` directory first.
2. Get the changes reviewed and approved by the dev using the `plannotator` skill.
3. Use `wireframe` skill to update the UI.

## CSS & Styling

Use tailwindcss for writing all css.

## Frontend javascript logic

Create a static javascript file, one per page.
